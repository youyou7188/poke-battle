# ポケモンチャンピオンズ ダメ計 (非公式)

スマホで対戦中に使えるポケモンチャンピオンズ用ダメージ計算。略称検索・相互計算・素早さ比較・ゲームのスクショからパーティ登録。

**使う: このリポジトリの GitHub Pages のページを開くだけ**(スマホのブラウザ推奨。ホーム画面に追加するとアプリのように使えます)。

## できること
- ダメージ計算(自分→相手 / 相手→自分)、確定数、急所時のダメージ
- 天候・フィールド・壁・ランク補正・状態異常・HP・てだすけ・おいかぜ、メガシンカの切替、へんげんじざい/リベロのタイプ変化
- 相手の型: 実戦でよく使われる型 / AS・HB などの配分 / 自由に調整
- 素早さ比較(最速・準速・スカーフ)
- パーティを10個まで保存。ゲームの「パーティ一覧」(能力・ステータス)のスクショから読み取って登録

保存データはそれぞれの端末のブラウザ内だけにあり、サーバーには送りません。スクショも端末の中だけで処理します。

## データと計算
- ダメージ計算: [Smogon damage-calc](https://github.com/smogon/damage-calc) のポケモンチャンピオンズ用ロジック (MIT License)
- 使えるポケモン・覚える技: [Pokémon Showdown](https://github.com/smogon/pokemon-showdown) のチャンピオンズ用データ (MIT License)
- 実戦の型: Smogon damage-calc の型データ
- 日本語名・画像: [PokeAPI](https://pokeapi.co/)
- スクショの文字読み取り: [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache License 2.0。使うときだけCDNから読み込み)
